# Super Bajaar — Storefront

Super Bajaar is a React storefront backed by the application's API and existing database.

The live catalogue should display saved active products, variants, categories, images, prices, and availability from the backend. Product and category changes must be made through the application and stored in the database; the website should not depend on CSV import templates or a separate synchronisation runner.

Keep credentials and database access server-side. Do not add fabricated catalogue data.
